# Pedro Ataídes - Portfólio Profissional

Bem-vindo ao repositório do meu portfólio pessoal! Este projeto foi desenvolvido para centralizar minha trajetória, competências técnicas, certificações e projetos práticos nas áreas de **Tecnologia e Segurança da Informação**.

🔗 **Acesse o site online:** [pedroataides.vercel.app](https://pedroataides.vercel.app/)

---

## Sobre o Projeto

O objetivo deste website é oferecer uma interface limpa, responsiva e de alta performance para apresentar minhas habilidades técnicas e estudos de caso (write-ups/laboratórios) para recrutadores, profissionais da área e entusiastas de cibersegurança.

### Desenvolvimento Assistido por IA
Durante a concepção, arquitetura e refatoração deste projeto, utilizei o **Claude Code** como ferramenta de apoio no desenvolvimento. A integração com a IA auxiliou na estruturação dos componentes, otimização de layout, boas práticas de código e agilidade na entrega da interface.

---

## Funcionalidades do Website

- **Design Responsivo:** Adaptado para visualização fluida em dispositivos móveis, tablets e desktops.
- **Vitrine de Projetos:** Detalhamento técnico de laboratórios, scripts e pesquisas em cibersegurança.
- **Seção Sobre & Habilidades:** Resumo das tecnologias, ferramentas periciais e stacks dominadas.
- **Contato Direto:** Links rápidos para redes profissionais (LinkedIn, GitHub, etc.).
